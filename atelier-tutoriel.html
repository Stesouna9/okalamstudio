1Créer son compte

Florian et Gabriel, une seule fois

  1. Ouvrir okalamstudio.com/atelier.html (ordinateur ou téléphone).
  2. Onglet Créer mon compte : prénom, adresse email, mot de passe (8 caractères minimum).
  3. On entre directement dans l'atelier. Les fois suivantes : Se connecter.
Il faut utiliser l'adresse que Gabriel a autorisée (pour Florian : celle de son compte Apple / TestFlight). Avec une autre adresse, le compte est créé mais l'atelier reste fermé : prévenir Gabriel, qui l'ajoute en une minute.

2Déposer des fichiers

Surtout Florian

  1. Choisir le projet à gauche (ex. VICE BREAK · fond du menu) et relire le brief en haut.
  2. Écrire une courte note (facultatif) : « crépuscule v2, grain plus léger ».
  3. Glisser les fichiers dans la zone pointillée, ou cliquer dessus pour les choisir. Plusieurs à la fois, 300 Mo maximum chacun.
  4. La barre se remplit, puis « Envoyé ✓ ». Le fichier apparaît dans la galerie avec le statut Reçu.
Les fichiers marqués Référence sont le point de départ : les ciels actuels de l'app (aube, jour, crépuscule, pluie, nuit), au format de l'iPhone 13 mini. Bouton Télécharger pour les récupérer en pleine taille.

3Les formats qui s'intègrent le plus vite

Pour iPhone et Android, un seul jeu de fichiers suffit

QuoiFormatPourquoi
Image finalePNG, couleurs sRGB, portrait 1290 × 2796Couvre le plus grand iPhone ; recadrée ensuite pour le 13 mini (1080 × 2340) et Android.
Calques pour l'animationPNG transparents séparés : ciel, soleil/lune, ville, palmiers, grillePermet de les faire bouger en profondeur (parallaxe) et de varier le ciel selon l'heure.
GrainTexture PNG 512 × 512 qui se répète sans raccordAppliquée par le code : plus légère et dosable.
SourcePSD aux calques nommés, ou AI / SVG pour les formes simplesLes silhouettes en vectoriel restent nettes sur tous les écrans.

Règles de cadrage

  • Horizon vers les deux tiers de la hauteur ; le logo VICE BREAK et le menu se posent par-dessus, au centre.
  • Rien d'important à moins de 150 px des bords haut et bas (encoche, barre de navigation).
  • Éviter le JPEG (pas de transparence) et le CMJN (couleurs ternes à l'écran).

Nommage conseillé

ciel-crepuscule-v2.png, calque-palmiers-v1.png, grain-512.png

4Suivre son travail

Chaque fichier affiche son étape. Chaque changement est aussi écrit dans la discussion, à droite.

ReçuLe fichier est arrivé ; Claude est prévenu.
En intégrationIl est en train d'être placé dans l'app.
Dans la version testUne version test l'inclut (numéro de build indiqué) : à ouvrir dans TestFlight.
ValidéGabriel le garde pour la prochaine mise à jour publique.
À revoirUn retour est écrit dans la discussion.

5Voir son travail dans l'app

Sur iPhone (TestFlight)

  1. Installer l'app TestFlight depuis l'App Store.
  2. Ouvrir l'email d'Apple « VICE BREAK – Vice Bay 86 is ready to test » (ou l'invitation dans TestFlight), puis Accepter avec le même compte Apple.
  3. Dans TestFlight : Installer VICE BREAK. Les nouvelles versions test arrivent au même endroit : bouton Mettre à jour.

Sur Android

VICE BREAK est sur Google Play : la version publique sert de référence.

La version test peut avoir quelques réglages de plus que la version publique : c'est normal, ce n'est pas un bug.

6Faire des retours

Pour Gabriel

  1. Ouvrir le fichier (clic sur la vignette pour l'agrandir).
  2. Écrire le retour dans la discussion : ce qui plaît, ce qui change, en une ou deux phrases. Entrée pour envoyer, Maj + Entrée pour aller à la ligne.
  3. Changer le statut sous la vignette : À revoir, Validé… Florian voit le changement tout de suite.

Demander à Claude

  • « Intègre le dernier dépôt de Florian dans une version test » : intégration, build TestFlight, statut mis à jour.
  • « Ajoute un projet à l'atelier : … » ou « Donne accès à l'atelier à telle adresse ».
Seul Gabriel (administrateur) peut changer les statuts et supprimer les fichiers des autres. Florian peut supprimer ses propres dépôts.

7En coulisses

  • Fichiers et messages restent sur le serveur d'OKALAM Studio, accessibles seulement aux membres de l'atelier.
  • À chaque dépôt, une veille sur le Mac du studio prévient Claude, qui prépare l'intégration. Une fois la version test envoyée, compter 5 à 10 minutes avant qu'elle apparaisse dans TestFlight.
  • Aucune version n'est publiée sur l'App Store ou Google Play sans l'accord de Gabriel.
